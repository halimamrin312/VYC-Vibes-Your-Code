# 5-Day AI Agents Intensive Vibe Coding Capstone Project Research

## Overview
The capstone project is the culmination of the 5-Day AI Agents Intensive course. The objective is to build an AI agent that demonstrates at least three key concepts from the course (e.g., multi-agent systems, ADK 2.0, MCP servers, security, or memory workflows) applied to a real-world problem.

## Project Tracks
Participants can choose from four categories for their capstone project:
1. **Agents for Business:** Solving enterprise problems (expense management, automation, internal tools, etc.). *(Your preferred track!)*
2. **Agents for Good:** Addressing societal challenges (education, healthcare, accessibility, etc.).
3. **Concierge Agents:** Building secure, helpful personal assistants.
4. **Freestyle:** Any creative or experimental agent project.

## Submission Requirements
To successfully submit the capstone project, you must provide:
- A Kaggle writeup detailing the project.
- A link to a public codebase (e.g., GitHub repository) containing your agent code.
- A video demonstration of the agent in action.
- A direct link to the deployed project/agent (if applicable).

## Key Deadlines & Recognition
- **Deadline:** Submissions are due by **July 6, 2026, at 11:59 PM PT**.
- **Rewards:** Completing the project earns you a Kaggle badge and certificate. Top projects in each track may receive Kaggle swag and social media recognition.

## Technology Stack Suggestions
- **Google Agent Development Kit (ADK 2.0)**
- **Antigravity** (Agentic IDE)
- **Model Context Protocol (MCP)** for connecting the agent to external tools and data sources.
